使用cloudflare的网站非常的多,cloudflare的服务器也遍布全球，但是在国内访问使用cloudflare的网站，服务器分配往往有点大病

**假设你在上海，离你最近的延迟很低速度很快的边缘服务器有NRT（东京）和 HKG（香港）而运营商会给你分配 LHR（伦敦）SJC（圣何塞）FRA（法兰克福）AMS（阿姆斯特丹）…因为距离太远，延迟会增加速度会降低而且经常会无法访问，这并不是你的网络问题，也不是cloudflare的问题.**

本工具并不会提高你的宽带速度，也不会使用代理或者修改您的IP地址，而是从cloudflare已公开的地址段内找到对于你来说延迟速度最好的那台服务器，并通过修改hosts的方式绕开运营商的分配

> [!IMPORTANT]
> 如果您使用中国移动宽带，那么可能大概率只能使用HKG的边缘服务器，并且速度并不好，这个工具也不能帮你优化

> [!IMPORTANT]
*cloudflare已经禁止使用这种方式搭建代理工具*

已知问题与解决方案

1. Q：修改后访问部分网站提示1034边缘节点受限</br>
A：cloudflare有免费计划和付费计划,免费计划的网站所有者不能使用付费计划的IP进行解析,当你测出的IP是付费计划才能使用的IP时，用这个IP去解析普通网站就会这样。
请确保您的head服务器或者测速服务器使用免费计划，这样您测出的IP无论付费还是免费都可以使用。

2. Q：为什么修改后失效了</br>
A：cloudflare边缘服务器的IP并不是固定的，而是动态变化的，有的时候会根据流量调度暂时关闭一些服务器。故障时请重新测新的。
